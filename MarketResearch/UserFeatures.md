# Video Game Recommendation Engines: User Feature Preferences

This document outlines the features gamers actually want versus those they find useless or frustrating.

## 1. Desired Features

### Deep Personalization (Beyond Genre)
- **Motivation-Based Filtering:** Users want recommendations based on *why* they play (e.g., "sense of discovery," "competitive challenge," "relaxing atmosphere") rather than just broad genres like "Action" or "RPG."
- **Gameplay Mechanics Focus:** Ability to filter by specific mechanics (e.g., "soulslike combat," "base building," "branching narratives").
- **Sub-genre Precision:** Distinguishing between vastly different games that share a broad tag (e.g., separating "Tactical Shooters" from "Arena Shooters").

### Control and Transparency
- **Sensitivity/Discovery Sliders:** A way to adjust how "safe" or "adventurous" recommendations are (e.g., a slider ranging from "Popular/Mainstream" to "Hidden Gems/Niche").
- **Exclusion Lists:** Robust "Not Interested" or "Ignore" features that actually prevent the game (and similar games) from appearing again.
- **Played Game Tracking:** The ability to mark games as "Already Played" (on other platforms) so they don't clog up recommendations.
- **"Because you liked..." Explanations:** Clear reasoning for why a game is being suggested to build trust in the algorithm.

### Integration and Utility
- **Library Syncing:** Importing libraries from Steam, Epic, PlayStation, and Xbox to avoid suggesting owned games.
- **Backlog Management:** Integrating recommendation discovery with a personal "to-play" list or backlog tracker.
- **Taste Profiles:** Matching users with "Taste Twins"—other players with highly similar rating histories.

---

## 2. Useless or Frustrating Features

### Popularity Bias
- **Trending Loops:** Systems that only recommend what is already popular or "top-selling," which users likely already know about.
- **New Release Obsession:** Prioritizing new games over higher-quality older games that are more relevant to the user's taste.

### Flawed Data and Tagging
- **Generic Tags:** Features that rely on broad tags like "Indie" or "Singleplayer," which provide zero insight into the actual gameplay experience.
- **User-Tag Junk:** Relying on meme-driven or inaccurate user tags (e.g., tagging a horror game as "Family Friendly" or a shooter as a "Visual Novel").

### Ineffective Feedback Loops
- **The "Broken" Dislike Button:** "Not Interested" buttons that don't seem to impact future recommendations or that forget the user's preference after a session.
- **Click-Bait Optimization:** Features designed to get a click rather than a long-term satisfied player (e.g., flashy trailers for mediocre games).

### Static Recommendations
- **Ignoring Evolving Tastes:** Systems that keep recommending the same genre the user liked five years ago, failing to recognize when a user has moved on to something else.
