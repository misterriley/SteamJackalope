# External Sources for User-Generated Game Difficulty Ratings

## Research Plan

### 1. Kaggle Datasets
- Search for game difficulty datasets on Kaggle
- Look for Steam game data with user ratings
- Check for game metadata with difficulty information

### 2. GameFAQs
- Investigate GameFAQs API or web scraping options
- Look for user-contributed difficulty ratings
- Check if difficulty is tagged in game profiles

### 3. HowDifficultIsIt.com
- Analyze the website's data structure
- Check if they provide an API
- Investigate web scraping possibilities

### 4. Other Potential Sources
- Steam forums and reviews
- Metacritic user reviews
- OpenCritic ratings
- GameSpot user reviews
- IGN community ratings
- Reddit game communities
- Twitch/YouTube game difficulty discussions

### 5. Academic Datasets
- Research papers on game difficulty
- Game analytics research datasets
- User experience studies

## Implementation Strategy

1. First, search Kaggle for existing datasets
2. If no suitable datasets found, investigate web scraping options
3. Document all potential sources with their pros/cons
4. Recommend the best approach based on data availability and quality
