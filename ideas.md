# How to use this file

- This file contains ideas that are vague and do not have a specific plan for how they should be pursued. They need to be broken down into actionable steps. Take an idea from this list, make a plan for how to accomplish it, and put the steps (in order if that is appropriate) into the relevant section in `tasklist.md`. When that is accomplished, remove the item from this list.
- Start with plans for ideas that would require the least amount of work or changes to the codebase.
